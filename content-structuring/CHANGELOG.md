# content-structuring 变更日志与维护说明

> 本文件仅面向技能维护者，**不列入 Agent 运行时加载路由表**，避免历史演进记录稀释整理任务的上下文注意力。

## 版本与同步规范

- **单一版本源**：版本号仅在 `SKILL.md` frontmatter `metadata.version` 维护一处；`references/*.md` 正文与 `scripts/*.py` docstring 不写版本号。
- **单源维护原则**：角色/覆盖豁免/步骤在 `references/spec.md`；编辑/视觉保真/实操/定量口径/抓取在 `references/editorial-standards.md`；语言分区与 4c–4f 闸门在 `references/language-and-gates.md`；访谈/圆桌/Keynote 混合与导读在 `references/interview-structures.md`；文件命名与统一外壳模板在 `references/templates.md`；过译判定在 `references/over-translation-guard.md`；机器词库在 `references/lexicon.txt`。跨文件通过 `SKILL.md` 路由表引用，严禁复制规则副本。
- **回归验证**：修改 `scripts/`、`fixtures/` 或契约条文后，使用无字节码模式运行全量回归：
  - `python -B -m unittest discover -s scripts/tests -p "test_*.py" -v`
  - 对 `fixtures/*.md` 运行 `python -B scripts/selfcheck.py`
  - 若改动涉及下游契约，同步运行 `md2wechat/scripts/tests/test_upstream_contract.py` 与 `md2html-lecture` 测试套件。
- **镜像同步**：若本机同时维护 `~/.codex/skills/content-structuring/` 镜像目录，发版验证通过后整目录同步以保持同版本。
