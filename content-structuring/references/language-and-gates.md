# 内容结构化整理 · 语言分区、语气迁移与 4c–4f 验收闸门（参考分册）

> 成稿与验收必读。机器词库单源在 `references/lexicon.txt`，AI/DevTools 概念标签与多义词辨析在 `references/over-translation-guard.md`；视觉保真与事实状态标记见 `references/editorial-standards.md`。

---

## 一、四层语言分区（含代码 / 可执行 Prompt / 公式保真）

默认交付物是**纯正中文深度文章**，拒绝「中文骨架 + 普通英语词汇夹写」，同时严防把专名、行业概念标签或可执行代码/Prompt 过译失效：

| 分区层级 | 覆盖范围 | 语言与保真规则 |
| :--- | :--- | :--- |
| **1. 中文叙述与原声层** | 导读、目录、深度解析、列表、**核心洞察、对谈实录 / 原声交锋 / 关键语录** | 直接用自然中文写清含义与腔调；严禁「先英后译」夹写或加粗英文普通词顶替翻译 |
| **2. 专名与概念标签层** | 公司/产品/模型/API、社区原生概念标签（角色/范式/工作流原语/对照组）、成组 taxonomy、行业缩写 | 保留官方英文（如 `Skill / Agent Loop / Loop / Graph / Harness / Evals`）；taxonomy 整组保留（如 `Agent → Loop → Graph`）；行业缩写（`IC/ASL/MTS/RAG/GTM` 等）首现注「中文全称（英文缩写）」，`MCP/API/LLM/SaaS` 等普及缩写可免 |
| **3. 代码 / 命令 / 可执行 Prompt / 公式保真层** | 代码围栏、CLI 命令与标志参数、配置文件键值、**可直接复用的英文 System Prompt / 指令模板**、数学公式 | 代码、命令参数与配置项原样保留；**供读者复制执行的功能性英文 Prompt 必须以代码块/引用块完整保留英文原文**（外围配中文拆解，严禁意译成无法执行的中文散文）；数学公式（`$...$` / `$$...$$`）完整保留符号、下标与约束定义，首现注明变量含义 |
| **4. 档案与外链层** | 元数据「原标题」、术语表专名列、延伸链接原标题、双语模式下的 `（原文："…"）` 副行 | 可保留原文；图片中文 `alt` 若需附带原片英文投屏标题，置于 `（原片标题：…）` 括注内 |

### 概念标签四问（先判指称，再查词库）

1. 官方产品、UI 对象、CLI 命令、代码符号或文件名？→ **留英文**。
2. 讲者刻意用来命名角色身份、范式、架构层或演化链对照组？→ **留英文标签**（首次可短括注中文释义，后文直接沿用英文）。
3. 译成中文会丢失圈内可检索性或混淆两个独立概念？→ **「中文说明（English）」或留英文**。
4. 仅表达普通动作、状态、程度或日常比喻（如 *refine*、*operationalize*、*super bullish*）？→ **译成自然中文**。

*注：口播自造词（coined term）首次写 `中文译名（English）`，后文统一用中文；用户显式指定「保留英文原文 / 中英双语」时覆盖语录语言并在自检注明。多义词（如 `rollout`、`hook`、`onboarding`、`demo`）语境辨析统一见 `over-translation-guard.md` 与 `lexicon.txt` 行内注释。*

## 二、语气迁移与原声占比参考线

### 1. 语气迁移（实录、解析引语、声口论证链通用）

目标：让中文读者「听见」讲者本人的说话方式，拒绝把所有人改写成同一种书面分析师腔。

- **必删噪音**：无信息结巴、重复启动词（嗯嗯、就是就是）、不改变态度的口头禅（*you know / I mean*）。
- **必留声纹**：自我修正、表强调的有意义重复、反问与祈使句式、半句打断、代表性语气词（每段留 1 处传神即可）、先否定再给答案的论证弯折，以及会改变理解的极少量舞台提示 `（笑）` `（停顿）` `（被打断）`。
- **句长与梗注**：短句风格者不合成复合长句，铺陈风格者不切成电报体；俚语与双关先译意再紧跟短注 `（原梗：…）`；全篇反复出现的标志性口号固定单一中文译法并记入自检声纹备注。主持人提问的锋芒、玩笑与自嘲与嘉宾同等保留。

### 2. 原声占比参考线（仅作下限提示，不阻断）

- **计算口径**：分子 = `对谈实录 / 原声交锋` 字数 + 解析层直接引语 + 声口模式第一人称论证链；分母 = 分子 + 解析/释义层编者叙述字数（不含元数据、导读、目录、自检，且剥离媒体 URL 与代码块）。
- **参考线**：信息型对谈三层 **约 35%**；单人演讲/长文（声口模式）**约 25%**；争辩型访谈 **约 50%**。低于参考线时在自检说明原因（如某节无张力已省略实录），不作为阻断失败条件，更不得为凑比例删减原声或解析背景。

## 三、保真与压缩的优先级（解析索引 vs 实录展开）

当可读性压缩（4e）与全息高保真发生张力时，严格按以下三步仲裁：

1. **语义、定量口径与事实绝对优先留下**：步骤、参数、论据、比喻、核心数字及其「口径四要素」完整保留；能删的只有结巴和同义重复。
2. **深度解析写「框架索引」，现场展开归「对谈实录」**：
   - 解析层负责背景衔接、口径说明，以及用紧凑短语表格/步骤列表提供**不展开折叠实录也能扫读完本节的结构化索引**（不计作散文复述）；
   - 解析层删掉的是「用第三人称把实录里的故事和对话再讲一遍」的重复叙述；若解析里有实录未覆盖的独有事实、案例或限定原话，压缩解析时必须**移回实录对应讲者的原话中**（4f），而编者第三人称口径说明则留在解析或收为节末 `> **事实边界**`，严禁套上 `**{全名}**：「…」` 冒充发言。
3. **篇幅越界判定以 `scripts/check_readability.py` 为唯一准绳**：
   - 4e-2 在同节存在非空实录/交锋时，仅当解析字数大于 `max(450, floor(同节实录字数的一半))` 时触发警告（450 字为保底上限，实录较短时解析仍可写至 450 字）。
   - **无实录节豁免 4e-1/4e-2**：单人演讲/长文的通用模板（声口模式）、多源合并中无内嵌实录的节、以及合法整块省略实录的节，因无 `### 对谈实录 / 原声交锋`（`d_len == 0`），**不受 450 字解析上限约束**，仅受 4e-3（单节 ≤3500 字）与 4e-4（单段 ≤300 字）约束。

## 四、机检闸门体系（4c / 4d / 判断行证据 / 4e / 4f）

成稿后必须运行 `python -B scripts/selfcheck.py {稿}`（存量修订加 `--before {备份稿}`）。**未跑机检严禁将对应自检行标 `✅`**。

### 1. 4c 语言纯净度与 4d 排版闸门（阻断级）

- **4c 扫描范围**：导读、目录、核心洞察、深度解析/释义、实录/交锋/语录。**自动遮罩豁免**：元数据原标题、术语表专名列、代码围栏与行内代码、普通 Markdown 链接、图片 `(url)` 路径、HTML `<img/video/figure>` 标签属性、`（原文：…）` 副行、`[ASR不确定…]` 标注及 `lexicon.txt` 白名单。

| 闸门项 | 脚本检查内容 | 通过标准 |
| :--- | :--- | :--- |
| **4c-1** | `ACTIONABLE_HITS`（`[blocking]` 裸词与必纠品牌错写） | **必须 = 0**（否则退出 1）；首现 `中文（English）` 括注不计入 |
| **4c-2** | `CONSECUTIVE_ENGLISH` + `[contextual]` / `[contextual-case-sensitive]` / 过译提示 | 逐条人工核实（译中文、补首现缩写全称，或确认为合法专名/标签后保留）；未核实禁标 `✅` |
| **4c-3** | 逐节复查 `### 对谈实录 / 原声交锋 / 关键语录` | 无残留英文普通半句（合法专名与概念标签除外） |
| **4d-1** | 结构分隔线 `---` 位置与计数（`normalize_spacing.py`） | 正文各 `##` 节间 **= 0**；全篇仅用于结构块边界（≤6 处） |
| **4d-2** | 连续多空行与围栏完整性 | 三连空行 **= 0**；代码围栏与 `<figure>` 块完好无劈裂 |
| **4d-3** | 标题格式、首层顺序与图片 URL 空格检查 | 正文 `##` 无 `1. ` 序号、无 `{#slug}` 显式锚点；`##` 后恰好 1 空行（对谈三层首块必为 `### 核心洞察`）；图片 URL 无裸空格 |

### 2. 判断行证据闸门（`check_judgment.py`，阻断级）

以下任一违规将令 `selfcheck.py` 直接退出 1：

- **人物声纹空标或失配**：「人物声纹」标 `✅`，但缺 `### 人物声纹` 原句证据，或原句（剥离 `**` 加粗格式符后）在正文中找不到。
- **遮名检验不足或复读**：声纹/遮名标 `✅`，但 `### 遮名检验` 不足前/中/后 3 条 `「…」→` 记录、存在重复句、复读了声纹已引句，或原句不在正文。
- **覆盖抽样空标**：「信息覆盖抽样」标 `✅`，但 `### 信息覆盖抽样` 下不足 3 条编号锚点。
- **原文图空标或张数失配**：「原文图」标 `✅`，但备注为空、写「无统计图」敷衍、正文残留未完成抓取的 `Page image`，或声明的稿内张数与正文实际远程图片/`<video>` 数量不一致。
- **争辩型假共识**：在**争辩型访谈模式**下，引号外的正文或自检通过项写出无否定词的「共识点 / 达成共识 / 双方一致 / 全文共识」。

### 3. 4e 可读性闸门（`check_readability.py`，警告复核级）

统计字数与重合度前自动剥离远程图片/图注 URL、`<video>`、`mermaid` 代码围栏与表格分隔符，消除配图对字数的扭曲：

| 子项 | 检查逻辑 | 阈值与处理方式 |
| :--- | :--- | :--- |
| **4e-1** | 解析与实录 8 字片段重合度（仅 `d_len > 0` 生效） | **≤20%**；超限则删去解析层对实录故事、数字与原话的散文复述 |
| **4e-2** | 解析字数上限（仅 `d_len > 0` 生效） | 大于 `max(450, floor(同节实录字数的一半))` 时警告；独有原话事实移入实录 |
| **4e-3** | 单节总字数 | **≤3500 字**；超限说明议题混杂，按子论点拆节或归位旁支问答 |
| **4e-4** | 段落长度与核心洞察长度 | 正文单段 **≤300 字**（长答在话题转换处断段）；`### 核心洞察` **≤50 字** |
| **4e-5** | 事实边界块密度、空壳实录与实录嵌图检查 | 带 `事实边界` 的节 **≤60%**；禁留空壳 `### 对谈实录`；禁在实录内嵌图 |

### 4. 4f 修订完整性闸门（`check_revision_loss.py`）

每次压缩、拆节或优化已有稿件前，**必须先另存修订前备份**，改后运行 `python -B scripts/selfcheck.py {修订后.md} --before {修订前.md}`：

- **4f-1（缺失数字与专名）**：比对修订前后丢失的数值与英文专名，逐项补回或说明合理去向（如 ASR 误识移入自检）。
- **4f-2（低保留率句子复核队列）**：从低到高逐句核查，换说法的意译放行，真丢失的事实原话补回实录。
- **4f-3（括注原子块完整，无 `--before` 亦常驻阻断）**：`[编者注：…]` / `［编者注：…］` 必须在同一段内闭合（栈式括号配对，自动跳过代码围栏内的 `]`）；严禁跨段切碎、严禁出现独立成行的 `]` 或实录内的 `「]」`。
- **4f-4（禁编者注冒充发言）**：修订前括注内的编者说明文字，严禁在修订后塞进 `**{全名}**（角注可选）：「…」` 充当人物原话。
- **4f-5（远程视觉资产保真）**：比对修订前后所有 `![...](https://...)` 与 `<video/img src="https://...">` 远程 URL 集合，严防压缩时误删原文配图或损坏链接。

## 五、受众可读性内化（可选）与存量复审流程

### 1. 受众可读性内化适配（用户指定跨文化受众或文化梗密集时启用）

1. **首现轻量补注**：对特定高校制度、文化典故、节目黑话或历史人物在**首次出现处**用短括注客观交代背景，后文不再重复。
2. **只增背景不降密度**：严禁删减专业细节；保持客观第三人称叙述，**严禁元叙述、严禁第二人称「你们」说教（原话引语内除外）、严禁生硬套用「相当于国内某某」类比**；补注中的英文同样遵守 4c。

### 2. 存量稿件复审最小 Diff 流程

优化已有 `*整理文档*.md` 时：先另存备份副本 → 跑 `selfcheck.py` 定位问题 → 按最小 diff 修复（4c 夹写与语录中文化 → 过译护栏回查 → 4d 排版与标题纯净 → 4e 去重与断段，注意不重排既有目录、不回溯改写已冻结的文件名短标题与发布日前缀）→ 跑 `selfcheck.py {新稿} --before {备份}` 完成上节 **4f-1 至 4f-5** 全项核验 → 更新自检报告与文末生成日期（若存在同茎下游讲义/公众号文件，按 `templates.md` 同步重建）。
