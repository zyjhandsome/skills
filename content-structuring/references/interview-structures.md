> 访谈结构与核心导读写法（v5.34）。跨文件引用按 `spec.md` 路由表定位。

## 对谈三层节结构（洞察 → 解析 → 实录）【v5.23】

**用途**：多人播客、访谈、圆桌、现场 Q&A 等素材，在保留《连线》式论证的同时，把主持追问、嘉宾幽默与对谈张力**结构化落地**——读者可先读分析，再下潜到「现场感」对话，无需回到原音视频。

### 何时启用

| 素材类型 | 默认 |
| :--- | :--- |
| **多人播客 / 访谈 / 圆桌**（≥2 说话人，Hard Fork、Lenny、Decoder、20VC、MAD 等） | **启用** |
| 单人演讲、主题演讲、纯长文、几乎无问答 | **不启用**（用「通用深度文章模板」） |
| 用户覆盖 | 「不要对谈实录」「恢复关键语录节」「专栏文章模式」「纯粹对话模式」等 |

### 先定叙事轴，再定章节

- **立场演化型信息访谈**：若核心嘉宾从旧判断转向新判断，先画出「旧判断 → 触发证据 → 新判断 → 组织实践 / 制度方案 → 个人行动」；这不是新模板，仍使用对谈三层。
- **章节推进测试**：每个 `##` 必须改变读者对全文论点的理解。若相邻两节只是同一因果链的不同追问，且合并不会损失关键事实或语气，就合并；禁止一问一节式议题百科。
- **标题承诺测试**：原标题的核心承诺若有原文支持，须进入正文 H1、全文论点或正文前段；若原标题本身夸张，导读须说明证据边界，不能照抄成已证实结论。
- **事实状态测试**：逐项标明是已发生案例、嘉宾预测、机构目标、主持人口播还是编者推断；预测与目标保留「预计 / 可能 / 试图 / 尚待验证」等限定。
- **人物声纹卡**：所有访谈都记录核心人物的句长、幽默、比喻、确定性与自我修正；争辩型模式另加回避、反击与权力关系。

### 每节固定三层（顺序不可颠倒）

```markdown
## {实质性节标题（含主张 + 核心实体）}

### 核心洞察

> {1–2 句**纯中文**结论，≤50 字；禁止英文谓语串。}

### 深度解析

{短段落：论点、数字、因果、案例、编者注/ASR 标注；分析师口吻。}

### 对谈实录

**{主持人全名}**：「{精编中文问句或引子}」

**{嘉宾全名}**：「{精编中文答句；保留幽默/锋芒}」
```

**硬规则**：

1. **节标题下禁止**在 `### 核心洞察` 之前写过渡段或大段叙事——铺陈进 **深度解析** 或 **对谈实录**。
2. **对谈实录**是**精编对谈**，不是字幕粘贴：删结巴、重复、无信息 filler；保留问答顺序、追问角度与关键数字。
3. **说话人**：`**{全名}**：「…」` 逐人换行；**禁止**「讲者 said」式叙述。同段已写全名时，实录内仍**每次换说话人写全名**（可读性优先）。
4. **一人长答**可占多句，不必硬凑对称轮次；**主持引子**（产品代际、数字锚点、新闻背景）须进解析或实录，不得因「主要是嘉宾答」而省略。
5. **深度解析与实录分工**：解析承担论证与数据；实录承担语气、接梗、锋利原话——**同一事实不在两处全文重复**；实录可补解析未覆盖的半开玩笑句、附着型口语。
6. **段落呼吸感（段内，非节间）**：深度解析仍遵守「单段 ≤4–5 行」；实录允许连续多行同一说话人，但单段引语不宜超过 **5 行**——过长则拆段或删冗余从句。**禁止**用节间多空行或 `---` 制造「呼吸感」。
7. **节间空白与分隔线【v5.24/v5.25】**：正文各 `##` 主题节之间**禁止**插入 `---`，节与节之间仅用**一个空行**分隔；`##` 与首个 `### 核心洞察` 之间**仅保留一行空行**（禁止连续多空行）。`---` 仅用于结构块边界：元数据后、导读后、目录后、以及**关键语录节前（通用模板保留篇末语录时）、延伸术语表 / 自检报告前**共 **≤6 处**——**不得**在每节正文末尾重复。成稿后过 **4d 节间空白验收闸门**。
8. **空壳实录**：若某节无值得单独摘录的对话张力（金句已在解析中），**省略**整块 `### 对谈实录`——**禁止**留空标题壳；须在自检「节结构」备注「N 节无实录已省略」。
9. **一项事实一个主要归宿**：关键数字、案例与判断在「深度解析」或「对谈实录」选择一个主要归宿；另一层只保留推进语气所必需的短句，不得完整复述。
10. **已发生不等于将发生**：同一段同时包含现状案例与未来时间表时必须拆清时态，禁止把预测并列改写为已发生。
11. **目标不等于成果**：认证中、试点中、计划中或讲者希望达到的结果，不得用无条件确定句呈现。
12. **编辑腔不过载**：不用「逼问 / 口径 / 画安全圈 / 自救 / 收束」等词替原对话制造对抗或结论；除非现场动作确实支持。

### 与篇末「关键语录与交锋时刻」

- **默认**：启用对谈三层时**省略** `## 关键语录与交锋时刻`，精彩表达已沉入各节 **对谈实录**。
- **例外**：用户显式要求「保留关键语录节」时可并存；篇末语录节只收**跨节**金句或用户点名保留句，**禁止**与各节实录大段重复。

### 与「纯粹对话模式」区分

| 维度 | 对谈三层节结构 | 纯粹对话模式 |
| :--- | :--- | :--- |
| 默认场景 | 多人播客/访谈 | 用户显式指定 |
| 核心洞察 / 深度解析 | **每节必有** | 弱化或省略 |
| 对谈比重 | 每节末尾一块实录 | 全文主体 |
| 篇末关键语录节 | 默认省略 | 常省略 |

### 元数据与自检

- 元数据表**可选行**：`| **文稿结构** | 对谈三层节结构（洞察→解析→实录） |`
- 自检**新增行**：`| 节结构（对谈三层） | ✅/⚠️/不适用 | 各节是否含三层；实录是否精编非复读；篇末关键语录节是否按规则省略或说明 |`

## 争辩型访谈 / 原声增强模式【v5.29】

**用途**：主持人与嘉宾、或多位嘉宾之间存在持续的框架冲突。目标不是替他们“总结出共识”，而是让读者看见：问题如何被提出、答案如何回避或推进、哪一句引发升级、哪些问题最终仍未解决。

### 触发判定：至少满足两类，且跨越多个主题

| 信号 | 典型表现 |
| :--- | :--- |
| **连续追问** | 同一问题被改写后再次提出；回答未解决主持人的设问 |
| **直接纠错** | 「不对」「完全错误」「你误解了」或明确否定对方事实框架 |
| **控制现场** | 打断、拒答、要求保留/删除某段、反问主持人动机 |
| **立场升级** | 从事实分歧升级到责任、权力、道德或制度合法性 |
| **无共识收束** | 结尾仍明确「我不同意」，或双方只承认分歧存在 |

**不触发的情形**：嘉宾批评未在场第三方；一处尖锐问题后恢复信息采访；多人播客存在不同意见但没有追问链；技术术语中的 `conflict/opposition`。这些仍用对谈三层，只在局部实录中保留张力。

### 动笔前：建立人物声纹卡

每位核心说话人至少记录五项：**句长与节奏、常用比喻、幽默方式、确定性强弱、面对追问时的动作**（正面回答/改写问题/转移/反击/自我修正）。声纹卡是内部工作底稿，不必原样输出；成稿须能遮住姓名仍大致辨认谁在说话。

精编可以删除无信息的口头填充，但必须保留会改变语气或权力关系的重复、停顿、自我修正、反问、抢话与短句。不要把所有人都改写成同一种“分析师腔”。

### 叙事原则：按冲突弧，而非议题百科重排

1. **保留升级顺序**：冷开场/预言 → 证据追问 → 责任与权力 → 个人或制度性对抗 → 未决收束。只有不影响因果与张力的相邻段落才能合并。
2. **原声先于解释**：先让人物完成一轮有意义的攻防，再提供背景、事实边界与概念释义。
3. **争议归属明确**：写「A 主张」「B 质疑」「A 未提供现场证据」，不用无主语的确定句替任何一方背书。
4. **禁止假共识**：若双方只同意“问题很重要”，不能写成对答案达成共识。可写「最低限度共同点」并明确范围。
5. **解析去重**：解析不逐句复述交锋，只补读者无法从原声直接得到的语境、定义、数字口径与认识边界。

### 每节结构

```markdown
## {取自现场原话或冲突动作的标题}

### 原声交锋

**{主持人全名}**：「{保留追问角度与节奏的精编中文。}」

**{嘉宾全名}**：「{保留短句、反问、幽默、自我修正或回避。}」

### 语境与释义

{只补必要背景、事实口径与推理边界；明确谁主张什么。}

### 未决问题

{仅当该节确有未解决的事实或价值冲突时使用；否则省略。}
```

**元数据**：`| **文稿结构** | 争辩型访谈（原声交锋→语境与释义→未决问题） |`

**自检新增行**：

- `| 争辩结构（v5.29） | ✅/⚠️/不适用 | 冲突弧按发生顺序；无假共识；未决问题有归属 |`
- `| 人物声纹 | ✅/⚠️/不适用 | 每位核心人物的句长、比喻、幽默、确定性与应对追问方式可区分 |`
- `| 原声与解析去重 | ✅/⚠️/不适用 | 解析只补语境与边界，不复述整轮对话 |`

**4c-3**：逐节扫描 `### 原声交锋`，规则与 `### 对谈实录` 相同。

## 多源合并稿（≥2 来源的合成稿）【v5.27】

**用途**：同一主题需要合并多条视频/播客/长文（如一位人物的多场访谈 + 第三方解读 + 综述）时，既非单一对谈、也非单源长文，单纯套「对谈三层」或「通用模板」都不贴合。本模式在**通用深度文章模板**基础上叠加四条规则：

| 规则 | 要求 |
| :--- | :--- |
| **1. 源口径标注** | 关键数字/事件标明出处口径，如「**@Scale 口径** 单日 150 PR」「**Platformer 口径** 20–30 PR」；避免把不同统计窗口的数字混为一谈 |
| **2. 多源一致性核对** | 按「防幻觉 > 多源一致性核对（第 8 条）」处理冲突数字/枚举：冲突写 `[编者注]` 并存，或点明「**互补 / 不同维度**」而非「互证」 |
| **3. 内嵌对谈实录** | 若某来源是多人对谈，可在相应节内嵌精选 `### 对谈实录`，其余节走通用模板；**不强制**全篇对谈三层 |
| **4. 来源清单入元数据** | 元数据「关联素材 / 内容来源」列出全部合并来源（链接 + 一句话定位），自检「素材覆盖」行登记合并了几路 |

**自检处理**：

- 「**节结构（对谈三层）**」行写 **多源合并（通用模板 + 内嵌实录）**，**不再**标「不适用」将就。
- 新增「**多源一致性**」行（与「防幻觉 > 第 8 条」联动），登记冲突项与处理方式。
- 「素材覆盖」行写明「**N 链合并**：…」。

## 核心导读写法（全文论点）【v5.26】

**定位**：`## 核心导读` 承担全文中心结构——常规稿合成**全文论点**；争辩型访谈合成**核心冲突**。读者只读导读就应把握中心主张或争议轴，而非话题串烧式议程回顾。

### 与各级「核心洞察」的分工

| 层级 | 作用 | 长度 |
| :--- | :--- | :--- |
| **全文论点**（导读首块） | 合成全篇**一条**中心主张（可含正反对照）；与文章/视频标题呼应 | 1–2 句，置于 `> **全文论点**：…` 引用块 |
| **核心冲突**（争辩型导读首块） | 写清双方采用的不同标尺、追问为何无法被同一答案化解；不裁定胜负 | 1–2 句，置于 `> **核心冲突**：…` 引用块 |
| **分层展开**（导读主体） | 按叙事弧线展开论据线索；段首用**实质性小标题**加粗（如 **战略转向。** **社会契约。**） | 2–4 短段，每段 ≤5 行 |
| **节级核心洞察** | 单节局部结论 | ≤50 字，见「对谈三层节结构」 |

### 硬规则

1. **中心前置**：导读**第一段**必须是 `> **全文论点**：…`；争辩型访谈改用 `> **核心冲突**：…`。两者都禁止以时间线或话题串开场。
2. **合成非串烧**：全文论点须是**可证伪的主张句**（因果/立场/标尺），不是「A 谈了 X，B 谈了 Y」的议程罗列。
3. **收束覆盖**：成稿前对照目录**末 2–3 节**，收束性论断（政治经济学、AGI 审慎、政策立场等）须在导读分层段中落笔——**禁止**导读只覆盖前半场。
4. **标题呼应与原标题承诺**：若篇名或原标题含嘉宾核心隐喻、金句或传播承诺（如「人人皆是利益相关者」「机会在无聊行业」），有原文支持时须在 H1、全文论点或紧邻一句中**显式落笔**，不得只留在元数据或末段例证；标题若夸张则在导读说明边界。
5. **分层标签**：2–4 段各以 `**{实质性标签}。**` 起首；标签须来自素材内在逻辑（如 **战略转向。** **伙伴与定位。** **社会契约。**），**禁止**机械写「第一部分/第二部分」。
6. **简洁版**：用户要「简洁版」时，保留全文论点块 + **1–2** 段分层展开；不得省略论点块。

### 反模式（成稿前自检）

| 反模式 | 症状 | 修正 |
| :--- | :--- | :--- |
| **话题串烧** | 导读像目录复述，读完不知中心主张 | 先写全文论点块，再删无关花絮 |
| **论点埋没** | 标题金句出现在第三段例证中 | 上提至全文论点或首段分层 |
| **半程导读** | 后半场收束节（治理/就业/AGI 等）未入导读 | 补末段分层，覆盖收束线 |
| **与正文脱节** | 导读主张后文无对应节 | 改论点或补正文，二者对齐 |
