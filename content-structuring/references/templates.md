# 内容结构化整理 · 文件命名、公共外壳与体裁插槽模板（参考分册）

> 本分册定义文件命名规则、下游同步契约、**单一公共文档外壳**与各体裁/覆盖模式的正文节结构插槽。成稿后运行 `python -B scripts/selfcheck.py {稿}`（修订存量稿加 `--before {备份稿}`），将机检输出的 `正文中文叙事`、`纯净排版`、`可读性机检`、`判断行证据`、`括注完整`（及修订时的 `修订完整性`）原样贴入自检报告表。延伸术语表只收读者需查阅的领域概念；ASR 纠错只进自检「术语校验」行。

---

## 一、文件命名规则与下游契约

### 1. 标准命名格式

新稿默认文件名：

```text
{发布日YYYYMMDD} {内容标题}_{实质性短标题}_整理文档.md
```

当实质性短标题与内容标题同义时省略短标题，退回两段式：

```text
{发布日YYYYMMDD} {内容标题}_整理文档.md
```

- **`{内容标题}`（取自原标题，保留来源信息）**：
  - 以元数据「原标题」为基准，**保留**节目/系列名、主讲或嘉宾、原标题核心要素；禁止用正文 H1、导读金句或章节主题替代 `{内容标题}`。
  - 非中文原标题默认**译为中文**后入文件名；公司、产品、人名与社区原生专名保留官方英文（如 `Latent Space`、`Claude Code`、`Agent Skill`）。中文原标题可略去「完整版 / 高清」等平台 SEO 赘词，不得改写为无关概括语。
- **`{实质性短标题}`（抽自正文 `# {实质性文章标题}`）**：
  - **24 个字符以内**，点明核心主张或核心实体（汉字计 1；英文专名整词保留，不从词中截断）。
  - **同义则省略**：译成中文后与 `{内容标题}` 信息等价时不重复（声口模式沿用作者核心表述作 H1 时常落入此分支）。
  - **非法字符与下划线**：两段均去除 `\ / : * ? " < > |` 与换行；标题内部的 `_` 改为空格，`_` 仅作段间分隔符。原标题含 `|` 时在元数据表单元格内转义写为 `\|`（下游自动还原为 `|`，禁改全角「｜」或截断后半段）。
  - **超长只压短标题**：完整文件名（含 `.md`）超过 120 字符时仅缩短短标题；再压即失主张时直接省略短标题，`{内容标题}` 永不截断。
  - **定稿冻结与存量不回溯**：短标题首次定稿即冻结，后续仅微调正文 H1 时不自动改文件名；已有旧稿 `{发布日} {内容标题}_整理文档.md` 不回溯改名（除非用户显式要求）。
- **日期前缀**：必须使用内容**真实发布日期**（`YYYYMMDD`），严禁用当前日期、抓取日或文档生成日替代；无法核实到具体日时先执行发布日期验证，仍无法确认则省略日期前缀并在元数据与自检注明原因。

示例（主张与原标题不同 vs 同义省略）：

```text
20261115 Latent Space：Claude Code 如何交付 Agent Skill_Skill 是可复用的一等对象_整理文档.md
20260522 介绍 Claude 4_整理文档.md
```

### 2. 下游联动契约（改名或修订已转化文稿时）

整理文档的文件名主干（stem）与读者向 `##` 节标题是下游 **`md2html-lecture`**（单文件讲义 HTML）与 **`md2wechat`**（微信公众号 HTML + 2.35:1 封面）的同茎校验键与锚点基准：

- **配图必须在源 `.md` 落笔**：下游 `md2html-lecture` 升级页面时仅恢复手加进 HTML 的 `figure.diagram`（Mermaid 流程图），**不保留手加进 HTML 的 `figure.source-figure`（原文配图）**；所有远程原图 URL 必须直接写在本整理文档内。
- **同茎同步重建**：若同目录已存在对应的 `.html` 讲义页或 `_公众号文章.html` / `_公众号封面.png`，修改整理文档内容或改名后，必须按 `md2html-lecture` 与 `md2wechat` 各自 `SKILL.md` 的标准工作流用新茎同步重建下游产物并清理旧茎残留，严禁只改 `.md` 导致源稿指纹或页脚失配。

## 二、单一公共文档外壳（所有体裁通用）

> 除正文节内插槽（见第三节）与导读首块标签（常规稿 `全文论点` vs 争辩型 `核心冲突`）外，**所有体裁（含对谈三层、争辩型访谈、单人声口模式、实操演示、多源合并及用户覆盖变体）一律共用以下完整外壳**，严禁删减元数据必填项或漏写人物/讲者背景块。

```markdown
# {实质性文章标题（声口模式优先沿用讲者/作者核心表述；争辩型取自核心冲突或原话）}

## 文章元数据

| 项目 | 内容 |
|------|------|
| **原标题** | {原文/视频标题；含 \| 时写 \\\|} |
| **内容链接** | {主 URL；多源合并可并列或见关联素材行} |
| **发布时间** | {YYYY-MM-DD} |
| **元数据抓取时间** | {YYYY-MM-DD 或 YYYY-MM-DD HH:mm} |
| **播放量/访问量** | {平台口径 + 数值，如「YouTube 观看次数：123,456」；无则 `未获取（原因）` / `不适用`} |
| **时长** | {音视频写 `HH:MM:SS` 或 `由字幕末条推算：…`；纯文稿写 `不适用（文稿）`} |
| **对谈人物** | {多人必填：**{主持人全名}**（身份） × **{嘉宾全名}**（身份）；单主讲/作者将左列改为 **讲者** 并填姓名与身份} |
| **文稿结构** | {对谈三层节结构（洞察→解析→实录） / 争辩型访谈（原声交锋→语境与释义→未决问题） / 通用深度文章（声口模式） / 实操演示保真 / 多源合并稿} |
| **关联素材** | {仅多源合并稿必选：逐条列出合并来源名称 + URL + 一句话定位；单源稿省略本行} |
| **内容来源** | {页面抓取（浏览器） / agent-reach 字幕 / 自动生成字幕⚠️ 等；注明原图外链状态或降级原因} |

{可选元数据副表：当音视频含平台 Chapters 或明确时间轴分段时保留，否则整块省略。下游 md2html-lecture 原生保留此副表，md2wechat 自动剥离。}

{可选元数据副表：当正文或 Show Notes / 简介包含讲者重点讨论的论文、GitHub 仓库、报告等真实外部链接时汇总于此，严禁顶层新开 `## 提及资源` 节；无则整块省略。}

> **人物背景**：
>
> **{全名 A}** {一人一段，只写此人身份与关键背景。单主讲/单作者时将首行标题改为 `> **讲者背景**：{一段简介}`。}
```

## 三、各体裁与覆盖模式的正文节结构插槽

### 插槽 A：对谈三层节结构（信息型多人播客 / 访谈 / 圆桌默认）

```markdown
## {实质性节标题：含主张 + 核心实体，禁写 1. 序号与 {#slug}}

### 核心洞察

> {1–2 句纯中文结论，≤50 字；禁止在此前写节下过渡段}

### 深度解析

{提供不展开折叠实录也能扫读完本节的结构化框架索引（短语对照表、步骤列表、背景与数字口径四要素）。远程原图 `![原文图 N：…](https://...)`、`<video>` 或 `mermaid` 仅嵌在本层段落之间。句末按需标 `［预测］` / `［目标］` 等，或在本层末尾收一行 `> **事实边界**：…`。}

### 对谈实录

**{主持人全名}**（14:20）：「{精编中文引子或追问；时间角注可选，跨时段合并写（14:20, 58:10 合并）}」

**{嘉宾全名}**：「{精编中文回答，保留幽默、反问、修正与推理节奏；长答在话题转换处断成下一段 `**全名**：「…」`，单段 ≤300 字；严禁在本层内穿插图片或代码块流程图}」
```

*注：若某节无值得单独摘录的对话张力（原话已入解析引语），**整块省略 `### 对谈实录`** 并在自检注明，严禁留空标题壳。*

### 插槽 B：争辩型访谈 / 原声增强模式（持续分歧与追问升级默认）

```markdown
## {取自现场原话或冲突升级动作的实质性标题}

### 原声交锋

**{主持人全名}**（08:15）：「{保留追问尺度与压迫节奏的精编中文}」

**{嘉宾全名}**：「{保留反击、改写问题、短句、停顿或拒答动作}」

### 语境与释义

{先声后解：只补读者无法从原声直接获知的背景、定量口径与认识边界；争议主张逐一明确归属（「A 主张…，B 质疑…」），禁止替双方总结假共识。远程原图或内联重构图表仅置于本层。}

### 未决问题

{仅当该节确有现场未解决的事实或价值分歧时保留本层，否则整层省略。}
```

### 插槽 C：通用深度文章 + 声口模式 / Keynote 混合 / 实操演示

```markdown
## {实质性节标题}

### 核心洞察

> {1–2 句纯中文结论，≤50 字}

### 深度解析

{• 单人演讲 / 作者长文（声口模式默认开）：保留讲者第一人称论证链（段首或段末用全名锚定一次「我」的归属）或较长直接引语，分析师句仅做衔接与事实标记。
 • 实操演示 / Live Coding 视频：按「环境前置卡（首节）→ 步骤目标 → 精确输入（命令/代码/配置/可执行英文 Prompt 原文块）→ 屏幕状态变化/预期输出 → 踩坑提示」闭环呈现，彻底消解「点这里/这个值」指代。
 • 远程原图 `![原文图 N：…](https://...)` + 紧邻斜体图注，或 L2 内联重构表/`mermaid` + `*（据原片 [14:20](url) 画面/口播整理）*` 置于对应段落后。}

### 对谈实录
{仅在「前主讲 Keynote + 后现场 Q&A」混合素材或「多源合并稿」中，当本节并入了观众/主持人问答或对谈源交锋时按需内嵌；纯单人长文/演讲节省略本块。}
```

### 插槽 D：用户显式覆盖变体（按 `spec.md` 豁免矩阵启用）

- **专栏文章模式**：`## {实质性标题}` 下不写 `###` 三级标签，直接用短段落（单段 ≤300 字）、自然过渡句与嵌入式引语行文。
- **纯粹对话模式**：`## {实质性标题}` → `### 核心洞察` → `### 对谈实录`（省略 `### 深度解析`，必要语境浓缩在首轮前 1–2 句 `[编者注：…]`）。
- **简洁版**：`## {实质性标题}` → `### 核心洞察` → 3–5 条紧凑要点列表（保留核心论断与关键数字口径）。
