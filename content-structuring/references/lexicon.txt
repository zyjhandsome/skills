#   - `scripts/check_4c.py` 启动时全量加载本文件；

#   - `references/language-and-gates.md`（4c 规则与译法指导所在分册）与

# 以 # 开头为注释。加载器自动为词首/词尾是字母数字的模式补 \b 边界。
#
# 分节语义：
#   [blocking]              裸露即判 4c-1 失败的普通叙述夹写词（脚本 ACTIONABLE_HITS）

#   [allow]                 专名白名单（大小写不敏感）：命中区域整体豁免
#   [allow-case-sensitive]  大小写敏感的专名白名单（如 Harness 产品名 vs harness 普通词）
#
