# 按任务选择验收

每次转换做内容与交付检查；脚本改动补回归；涉及模板或交互再做浏览器检查。
报告实际执行结果，浏览器测试被跳过时不能声称浏览器验收通过。

## 每份产物

- 正文 `##` 数与输出 `sections=` 一致，排除导读、目录、术语、元数据、自检。
  核对未知三级标题和无三级标题的正文，代码块中的 `#` 不改变文章结构。
- TOC 对应正确章节，只列二级结构；重复标题有不同锚点。正文序号和目录
  都是 01、02；`12%`、`2012 年` 等标题数字保留，标题原有序号不重复显示。
- 人物/讲者背景在页头后、导读前，保持分段；术语表、元数据、自检报告
  在末尾折叠，额外元数据表保留所属标题，自检的三级块不合并。
- 引语、代码字面内容、列表、表格完整；没有遗留 `<p>---</p>` 或源目录。
- 主持人角色依据人物元数据，连续同人发言合并；人物较多时检查配色。
- 无未处理 WARN；升级无 FAIL，保存/恢复图表数一致。
- 页头人工调整保留正确，未调整字段按源稿更新；来源文件名匹配当前 `.md`。

## 脚本或模板变更

在 Skill 根目录运行：

```bash
python -X utf8 -m pytest scripts/tests/ -q
```

测试需要 pytest。内容测试包括围栏/行内代码保真、唯一锚点、页头编辑、图表保留、
升级失败不覆盖旧页、告警透传，以及连续升级不重复加图。
检查单文件生成路径和退出码；另用带中文路径的临时目录验证批量命令。

## 浏览器行为

打开实际 HTML 并检查：

- 「只看要点」初始按下，实录/交锋关闭；一键展开后重载保留选择，单块仍可独立打开。
- 「只看嘉宾」仅有主持人角色时出现，默认关闭；开启只隐藏主持人，重载保留。
- 打印展开全部面板，并包含被嘉宾筛选隐藏的主持人；退出打印后恢复之前状态。
- 浅/深色切换后字、徽章、链接、表格与代码清晰，重载无主题闪烁。
- 图示在核心洞察之后、深度解析之前；在线正常渲染，阻断 CDN 后支持的图
  显示 `甲 → 乙` / `甲 ⇢（说明）乙`，切换主题不丢图文。
- 移动端目录可打开、关闭、Escape 返回触发按钮；页面无横向溢出。

仓库提供可选浏览器回归，需要 Playwright 和本地 Chromium/Edge 可执行文件。
设置 `MD2HTML_BROWSER` 后运行；测试使用独立浏览器上下文、临时稿件并阻断 CDN。
它验证离线图示，不代替在线 Mermaid 渲染检查。

PowerShell 示例（使用本机实际路径）：

```powershell
$env:MD2HTML_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
python -X utf8 -m pytest scripts/tests/test_browser.py -q
```

若无可用浏览器，报告已通过的结构测试和未执行的交互检查，不自动下载安装依赖。

## 全局设计变更时追加

同时读取 design-decisions.md。核对所有块外沿共享 `--measure`，正文表格不拉宽，
面板内表格留在面板里，刻意宽图/宽表才用 `.full-bleed`。
检查洞察/解析/实录只显示一个层级 pill；深浅色图形边框、强调芯片和徽章可读。
长文目录滚动保持活动项可见，不因折叠导致阅读位置明显跳动。
